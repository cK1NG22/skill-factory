# workflow-section-skill

Research skill that runs a structured workflow without using "Phase N" section headings.

## Workflow

1. Read the research question.
2. Search primary sources and extract candidate claims.
3. Cross-check each claim against a second independent source.
4. Rank claims by source tier using the 4-tier hierarchy.
5. Write the final synthesis document.

## Notes
Each step is expected to complete before the next begins. There is no concurrency.
